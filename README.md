# Cyber-Luxury Landing Page

A premium, motion-rich, and visually stunning landing page built with **Next.js 16**, **React 19**, and **Framer Motion**. This project features a state-of-the-art "Cyber-Luxury" aesthetic with glassmorphism, interactive animations, and a fully responsive design.

## ✨ Key Features

- 💎 **Premium Aesthetic**: Sleek "Cyber-Luxury" design with deep dark modes and vibrant accents.
- ⚡ **Performance Optimized**: Built on Next.js 16 for lightning-fast loading and SEO readiness.
- 🎨 **Framer Motion Animations**: Smooth, high-end transitions and interactive micro-animations.
- 📱 **Fully Responsive**: Optimized for all devices, from mobile to ultra-wide displays.
- 🪄 **Glassmorphism**: Elegant translucent UI elements with backdrop-blur effects.
- 🧩 **Lucide Icons**: Professional, consistent iconography throughout the site.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Animations**: Framer Motion
- **Styling**: Tailwind CSS v4.0
- **Icons**: Lucide React
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0 or higher)
- npm, pnpm, or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rakibulhasanshuvo/Cyber-Luxury-Landing.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Deployment

### Deploy to Vercel

The easiest way to deploy this project is via the [Vercel Dashboard](https://vercel.com/new).

1. Connect your GitHub repository.
2. Select the `cyber-luxury-landing` project.
3. Click **Deploy**.
